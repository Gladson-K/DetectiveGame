# DetectiveGame — agent rules

Tier: **B (default until classified in RISK-REGISTER.md)**. See `@governance/RISK-REGISTER.md` for the gate.

1. Read `@governance/AGENTS.md`, `POLICY.md`, `DATA-MAP.md`, and `SECURITY-BASELINE.md` before changes to code, data, or models.
2. Data restrictions: Follow @governance/DATA-MAP.md. Never send secrets, personal data, or restricted datasets to models or web tools.
3. Commands: Use the commands documented in the repository README or Makefile; run focused tests after edits.
4. Never publish, deploy, push, or contact external services without approval.
5. Record AI assistance and human verification in the change description.
6. Run focused tests/lint after edits; report files, commands, results, and risks.
